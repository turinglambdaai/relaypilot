# RelayPilot 使用指南

[English](USER-GUIDE.md) · **简体中文**

探索统一网络配置、确定性路由决策和受监督的引擎适配器。

## 当前可用状态

免费架构实验，不销售、不订阅、不接商业激活；现行源码许可限制仍然有效。

## 平台与安装

架构 Alpha，已有源码 CLI 与回环引擎纵切。桌面或移动源码基础不等于已发布的 VPN、TUN 或系统全局网络客户端。

源码安装与运行命令见 [README](../README.zh-CN.md)；发布附件不等于完整部署服务。

## 第一次使用

1. 使用合成 profile 和已文档化的 CLI 工作流，先校验再求值路由。
2. 运行固定版本引擎前，先检查 DecisionTrace 和适配器 dry-run 输出。
3. 测试保留在可丢弃的回环环境，不导入真实订阅，也不将其用作系统网络通道。

## 数据、备份与恢复

保留 profile 原件及引擎版本、摘要证据。诊断轨迹可能包含目的地址与凭据，报告使用脱敏合成夹具。已知可用的网络配置应独立保存在实验之外。

## 联网、密钥与隐私

即使控制模型位于本地，配置的引擎也可能产生真实连接。不保证匿名浏览、流量安全、VPN 防护或服务可用性。

## 已知限制

当前没有公开发行附件。平台成熟度与实际网络接管仍需明确验收；规划平台不等于已支持产品。

## 升级与停止使用

升级前备份配置与数据，核对源码版本和依赖。先在隔离环境验证，再替换正在使用的版本。停止服务或程序后再清理本机数据；外部平台上的内容与凭据需在相应平台单独管理或撤销。

## 获得帮助

在 [GitHub Issues](https://github.com/turinglambdaai/relaypilot/issues) 反馈，中文或英文均可。提供版本、系统与架构、安装渠道、复现步骤、预期和实际结果。先用合成样本复现；不要附上密钥、授权文件、数据库、原始私密文档或完整日志。公开支持不承诺响应时限。
